이용 안내

  • 내 휴대전화의 GPS 위치를 실시간으로 보여줍니다.
  • 좌표는 이 화면에만 표시되며 서버로 전송하거나 저장하지 않습니다.
  • [동의]를 누르면 위치 권한 창이 나타납니다.
  • 권한 창에서 [이번에만 허용]이 보이면 반드시 그것을 눌러 주세요. 그래야 다음 접속 때 다시 묻습니다.
다른 허용(항상 허용 등)을 눌렀다면?
삼성 인터넷: 메뉴(≡) → 설정 → 사이트 및 다운로드 → 사이트 권한 → 위치 → 허용된 사이트에서 이 사이트 삭제
iPhone Safari: 설정 → 앱 → Safari → 위치 → 이 사이트 → '묻기' (iOS 17 이하는 설정 → Safari → 위치)
※ 기기마다 설정 방법이 조금 다를 수 있습니다.

종료할까요?
